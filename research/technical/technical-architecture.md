# Technical Architecture Index

The full V1 architecture is split into focused documents under `research/technical/architecture/`:

- `overview.md` — protocol summary and contract list
- `flows.md` — top-level and activity diagrams
- `invariants.md` — invariants, formulas, accounting flow
- `components/*.md` — per-contract specs for OllaCore, StAztec, RewardsVault, StakingManager, WithdrawalQueue, SafetyModule, GuardianMultisig
- `interfaces-and-roles.md` — external interfaces and AccessControl matrix
- `operations-and-controls.md` — operational cadence and safety controls
- `launch-constraints.md` — V1 scope and guardrails
- `milestones.md` — build milestones and success criteria
- `v2-roadmap.md` — deferred features
