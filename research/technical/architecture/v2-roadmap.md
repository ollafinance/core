# Appendix: V2 Roadmap

Features deferred to V2:

1. Multi-validator system (ValidatorRouter, ValidatorRegistry; dynamic rebalancing and proportional delegation).
2. Multi-oracle consensus (OracleConsensus with quorum).
3. Advanced fee distribution (FeeDistributor, validator commissions).
4. Progressive decentralization (DAO governance, timelock, sunset).
5. Enhanced safety features (automated TVL cap increases, additional breakers).
6. Additional audits (formal verification, economic analysis).
