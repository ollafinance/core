# StakingManager — Staking Delegation and Keys

| Section | Specification |
| --- | --- |
| **Purpose** | Stakes AZTEC into the canonical Aztec rollup using provider-managed attester keys, tracks activated/pending exits, claims sequencer rewards into `RewardsVault`, and returns matured unstaked funds to `OllaCore`. |
| **State Variables (typed)** | `IERC20 stakingAsset`; `IAztecRollupRegistry rollupRegistry`; `IRewardsVault rewardsVault`; `address core`; `address governance`; `ProviderConfig provider`; `Queue providerQueue`; `address[] activatedAttesters`; `mapping(address=>uint256) attesterIndex`; `mapping(address=>bool) isActivatedAttester`; `address[] pendingUnstakeRequests`; `mapping(address=>bool) isUnstakePending` |
| **Events** | `ProviderSet(address admin,address rewardsRecipient)`; `KeysAddedToProvider(address[] attesters)`; `StakedWithProvider(address attester,uint256 amount)`; `UnstakeInitiated(address attester,uint256 amount)`; `UnstakeFinalized(address attester,uint256 amount)`; `UnstakedFundsClaimed(uint256 amount)`; `RewardsHarvested(uint256 amount)`; `QueueDripped(address attester)` |
| **Roles and Permissions** | `CORE_ROLE` (OllaCore entrypoints); `STAKING_PROVIDER_ADMIN_ROLE` (key queue + provider config); `DEFAULT_ADMIN_ROLE` (role admin + upgrades gated by `governance`) |
| **Key Functions (typed and role scoped)** | `initialize(IERC20,address,address,address,address,address,address)` — initializer; `stake(uint256 amount)` — only `CORE_ROLE` (stakes `floor(amount / activationThreshold)` attesters, bounded by queued keys); `unstake(uint256 amount)` — only `CORE_ROLE` (initiates exits across activated attesters until enough); `cleanActivatedAttesters()` — only `CORE_ROLE` (syncs activated list vs rollup exit state); `getUnstakedFunds() returns(uint256)` — only `CORE_ROLE` (finalize exits + transfer to core); `harvestRewards() returns(uint256)` — only `CORE_ROLE` (calls `claimSequencerRewards(rewardsVault)` then `rewardsVault.postReceiveFundsHook`); `getClaimableRewards() view returns(uint256)` — only `CORE_ROLE`; `addKeysToProvider(KeyStore[] keyStores)` — only `STAKING_PROVIDER_ADMIN_ROLE`; `dripQueue(uint256 count)` — only `STAKING_PROVIDER_ADMIN_ROLE` (dequeues keys and emits `QueueDripped`); `setProviderRewardsRecipient(address)` — only `STAKING_PROVIDER_ADMIN_ROLE`; `getStakingState() view returns(StakingState)`; `getQueueLength() view returns(uint256)`; `getProviderConfig() view returns(ProviderConfig)`; `getActivatedAttesterCount() view returns(uint256)`; `getPendingUnstakeCount() view returns(uint256)`; `isUnstakePending(address) view returns(bool)` |
