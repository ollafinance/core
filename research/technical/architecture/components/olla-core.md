# OllaCore — Core Staking Contract

| Section | Specification |
| --- | --- |
| **Purpose** | Main vault (ERC7540) for deposits and withdrawals, staking flows, accounting snapshots, system state control via safety. |
| **State Variables (typed)** | `address stAztec`; `address stakingManager`; `address withdrawalQueue`; `address rewardsVault`; `address safetyModule`; `AccountingState accountingState`; `FlowCounters flowCounters`; `LatestReport latestReport` |
| **Events** | `Deposit(address,address,uint256,uint256)`; `WithdrawalRequested(uint256,address,uint256,uint256,uint256)`; `WithdrawalFinalized(uint256,uint256)`; `WithdrawalClaimed(uint256,address,uint256)`; `RewardsHarvested(uint256)`; `AccountingUpdated(uint256,uint256,uint256,uint256)`; `AttestersStateRead(uint256,uint256,uint256)`; `Rebalanced(uint256,uint256,uint256,uint256)`; `Paused()`; `Unpaused()` |
| **Roles and Permissions** | `DEFAULT_ADMIN_ROLE`, `GUARDIAN_ROLE`, `OPERATOR_ROLE`, `CORE_ROLE` |
| **Key Functions (typed and role scoped)** | `function deposit(uint256 assets,address recipient)` — public; `function requestRedeem(uint256 shares,address recipient)` — public; `function claimActiveRequest(address owner)` — public; `function claimRequestById(uint256 requestId)` — public; `function rebalance()` — only `OPERATOR_ROLE`; `function updateAccounting()` — only `OPERATOR_ROLE`; `function finalizeWithdrawals(uint256 available)` — only `OPERATOR_ROLE`; `function totalAssets() view returns(uint256)` — view; `function exchangeRate() view returns(uint256)` — view; `function convertToShares(uint256 assets) view returns(uint256)` — view; `function convertToAssets(uint256 shares) view returns(uint256)` — view; `function previewDeposit(uint256 assets) view returns(uint256)` — view; `function latestReport() view returns(LatestReport)` — view; `function flowCounters() view returns(FlowCounters)` — view; `function accountingState() view returns(AccountingState)` — view; `function pause()` — only `GUARDIAN_ROLE`; `function unpause()` — only `GUARDIAN_ROLE` |
